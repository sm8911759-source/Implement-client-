TC-01 – High Impact UI Policy

Set Impact to High.

Expected:

Action:
Set Impact to High.

Expected:
Urgency should become read-only.


TC-03 – Automatic Urgency

Action:
Set Impact to High.

Expected:
Urgency should automatically become High.


TC-04 – Assigned To Validation

Action:
Set Impact to High.
Leave Assigned To empty.
Click Submit.

Expected:
Record should not save.
Error should appear.


TC-05 – Successful Save

Action:
Set Impact to High.
Select Assigned To.
Click Submit.

Expected:
Incident should save successfully.
